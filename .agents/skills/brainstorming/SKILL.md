# Brainstorming Skill

Skill ini dijalankan di tahap awal sebelum penulisan kode dimulai.

## Langkah Kerja
1. **Klarifikasi Scope**: Tanyakan tujuan utama, batasan sistem, dan ekspektasi pengguna.
2. **Eksplorasi Alternatif**: Berikan 2–3 opsi arsitektur atau pendekatan teknis beserta kelebihan dan kekurangannya.
3. **Penyusunan Desain Bertahap**: Sajikan rancangan solusi dalam beberapa bagian terstruktur:
   - Ringkasan Solusi & User Journey
   - Arsitektur Komponen & Alur Data
   - Perubahan Skema / File
   - Rencana Pengujian
4. **Validasi Pengguna**: Minta masukan dan persetujuan pengguna atas desain tersebut.
5. **Simpan Dokumen Spesifikasi**: Simpan dokumen yang disetujui di `docs/specs/YYYY-MM-DD-<nama-fitur>.md`.
